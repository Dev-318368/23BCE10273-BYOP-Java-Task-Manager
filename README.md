# Java Task Manager System

## Project Overview

The **Java Task Manager System** is a desktop-based application developed using Java Swing and SQLite database.
This system allows users to manage daily tasks efficiently by providing features to add, view, and delete tasks through a graphical user interface (GUI).

The project demonstrates the practical application of Java programming concepts such as Object-Oriented Programming (OOP), GUI development, and database connectivity using JDBC.

---

## Problem Statement

Students and individuals often forget assignments, deadlines, and daily tasks due to the lack of a simple centralized task management system.
Manual tracking of tasks is inefficient and prone to errors.

---

## Objective

The objective of this project is to develop a Java-based task management application that:

* Allows users to add tasks
* Displays all tasks in a list
* Deletes selected tasks
* Stores tasks permanently using a database
* Provides a simple graphical user interface

---

## Features

* Add new task
* Display list of tasks

## How to Run the Project

### Step 1 — Compile the Program

Open terminal in the project folder and run:

```
javac TaskManager.java TaskDatabase.java
```

### Step 2 — Run the Program

```
java TaskManager
```

---

## How to Use the Application

1. Launch the application
2. Enter a task in the text field
3. Click **Add Task**
4. The task will appear in the list
5. Select a task and click **Delete Task** to remove it
